# Roadmap

## Phase 1: Content (now)
- [ ] Draft all three courses
- [ ] Test each lab on a low-cost laptop with no internet after setup
- [ ] Pilot one Saturday session with a small group
- [ ] Revise from feedback

## Phase 2: First countries
- [ ] Choose one or two pilot countries with a local host
- [ ] Run sessions, then support each trainer's first cascade session
- [ ] Translate the most-used course

## Phase 3: Grow without us
- [ ] Local trainers run sessions on their own
- [ ] Local trainers become maintainers of their translations
- [ ] Publish what worked and what did not
