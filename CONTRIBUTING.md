# Contributing

Thank you. Every fix helps a trainer somewhere.

## Ways to help
- Fix a typo or an unclear step.
- Report a lab that did not work, and say what computer and system you used.
- Add a local example (a local law, company, or community).
- Translate a course.
- Share how your session went.

## If you are new to GitHub: fix something in your browser
1. Open the file you want to change on github.com.
2. Click the pencil icon (top right of the file). It says "Edit this file."
3. Make your change in the text box.
4. Scroll down. In the box under "Commit changes," write one line saying what you changed.
5. Click the green **Propose changes** button.
6. On the next page, click the green **Create pull request** button.
7. A maintainer will review it and reply.

## To report a problem
1. Click the **Issues** tab at the top of the repository.
2. Click the green **New issue** button.
3. Write what you were doing, what you expected, and what happened.
4. Click **Submit new issue**.

## Writing style
- Plain words. Short sentences.
- Steps are numbered, one action per step.
- Name the exact button or menu you click.
- No made-up numbers. If you cite a fact, link the source.
- Keep files plain Markdown, so they work on slow connections.

## Translations
Put translations in a folder named for the language code, for example `courses/01-open-source-basics/es/`. Open an issue first so two people do not translate the same thing.
