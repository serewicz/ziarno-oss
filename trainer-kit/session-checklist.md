# Session checklist

## Two weeks before
- [ ] Room booked for the full day, with power outlets for every laptop
- [ ] Projector or large screen and the right cable
- [ ] Attendee list and contact details
- [ ] Pre-work sent (GitHub account for Course 1, Ollama install for Course 2)

## One week before
- [ ] Every lab tested on a slow laptop
- [ ] USB sticks loaded with installers and models (Course 2)
- [ ] Class repo created (Course 1)
- [ ] Printed copies of labs and feedback forms
- [ ] Backup internet (phone hotspot)

## On the day
- [ ] Arrive one hour early. Test Wi-Fi, projector, and power.
- [ ] Name the contact person for the Code of Conduct
- [ ] Water, coffee, lunch arranged
- [ ] Sign-in sheet

## After
- [ ] Collect feedback forms
- [ ] Check in with each trainer about their cascade date
- [ ] Open issues for any broken labs
