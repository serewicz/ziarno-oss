# Ziarno Open Source curriculum

A free, self-paced and classroom-ready path for working tech practitioners. Use it on your own, in a study group, or alongside the [Saturday courses](../courses/).

Every module has learning objectives, a lesson outline, a hands-on exercise with step-by-step instructions, a short quiz, and free resources. We prefer openly licensed sources and list each one's license.

## Levels
- **Foundation:** for anyone in tech. No open-source experience needed.
- **Practitioner:** for people who will use, change, and run open source at work.
- **Leader:** for people who will set policy, build communities, and train others.

## Suggested paths
- **Everyone:** 1, 2, 3.
- **Engineers and admins:** add 6, 7, 8, 9.
- **Managers and policy staff:** 1, 2, 5, 6, 10, 12.
- **Community builders and trainers:** 1, 3, 4, 11, then teach module 1 to others.

The order follows [HOW-TO-START.md](../HOW-TO-START.md): learn the basics, practice InnerSource inside your own office, set up the open source office, then move work into the open.

## Low bandwidth
- Plain text. Reads on a phone and prints well.
- Large downloads (Ollama models, Syft) are marked. Get them once on a good connection and share by USB stick.
- Resources marked "LF terms" are free but need an account and are not openly licensed.
