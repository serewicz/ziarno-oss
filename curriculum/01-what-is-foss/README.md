# Module 1: What is FOSS: history, freedoms, licenses

**Level:** Foundation  
**Time:** about 3 hours  
**Needs:** a laptop or a phone with a browser; some exercises need an internet connection once.

## Learning objectives
By the end you will be able to:
- Explain the four software freedoms in your own words
- Tell the difference between free software and open source, and why both terms exist
- Name the two main license families (permissive and copyleft) and give one example of each
- Pick a license for a small project and say why

## Lesson outline
1. Short history: shared code in early computing, the GNU project (1983), Linux (1991), the term "open source" (1998)
2. The four freedoms: run, study, share, change
3. The Open Source Definition and OSI-approved licenses
4. Permissive (MIT, Apache-2.0, BSD) vs. copyleft (GPL, AGPL, MPL)
5. What "public domain" and Creative Commons mean, and when to use CC for content instead of code
6. Common mistakes: no license at all, mixing incompatible licenses

## Hands-on exercise: Pick a license for a real project
1. Open a web browser and go to https://choosealicense.com/
2. Read the three choices on the front page. Write down which one fits a project at your office that you would like others to reuse.
3. Click **I want it simple and permissive**. Read the box on the right called **Permissions, Conditions, Limitations**.
4. Go back. Click **I care about sharing improvements**. Compare the same box. Write one sentence on what is different.
5. Click **Appendix** at the bottom of the page (or open https://choosealicense.com/appendix/). Find the row for **Apache License 2.0** and the row for **GNU GPLv3**. Note which one requires you to share source code when you distribute changes.
6. Open https://opensource.org/licenses and search the page (Ctrl+F, or Find in page on a phone) for the license you picked. Confirm it is OSI-approved.
7. On paper, write: project name, license chosen, one reason. Share it with the person next to you.

## Quiz
1. Name the four freedoms.
2. Is code with no license open source?
3. Which is copyleft: MIT or GPL?
4. Which body keeps the list of approved open-source licenses?

<details><summary>Answers</summary>

1. Run, study, change, share (redistribute copies and modified copies).
2. No. Without a license, the default is all rights reserved.
3. GPL.
4. The Open Source Initiative (OSI).

</details>
