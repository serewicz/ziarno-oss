# Module 5: Running an OSPO and open-source policy for government

**Level:** Leader  
**Time:** about 5 hours  
**Needs:** a laptop or a phone with a browser; some exercises need an internet connection once.

## Learning objectives
By the end you will be able to:
- Explain what an Open Source Program Office (OSPO) does
- Draft a one-page open-source policy for a ministry
- Set up a simple intake and approval process

## Lesson outline
1. What an OSPO is: a small team that sets rules, helps teams use and release open source, and tracks what is in use
2. OSPO stages: start, grow, mature
3. Policy basics: using open source, contributing back, releasing public code
4. Public money, public code
5. Inventory: knowing what open source you run
6. Learning from others: TODO Group, EU OSOR, Foundation for Public Code
7. Link to [HOW-TO-START.md](../../HOW-TO-START.md): the national open source office

## Hands-on exercise: Draft a one-page policy
1. Open https://todogroup.org/resources/guides/ and open the guide on creating an open source program.
2. Open https://standard.publiccode.net/ and read the list of criteria on the front page.
3. In a document, write four headings: **Using open source**, **Contributing to open source**, **Releasing our code**, **Who decides**.
4. Under each heading write two or three plain sentences. Example: "Staff may use OSI-approved software without approval for internal tools."
5. Under **Who decides**, name a role (not a person), and a reply time, for example five working days.
6. Show it to one lawyer or procurement officer and one engineer. Write down their top concern each.
7. Revise and keep it to one page.

## Quiz
1. Name three jobs of an OSPO.
2. What does "public money, public code" mean?
3. Why keep the policy to one page?

<details><summary>Answers</summary>

1. Set policy; help teams use and release open source; track what is in use; train staff.
2. Software paid for with public money should be released as open source when possible.
3. So people read it and follow it.

</details>
